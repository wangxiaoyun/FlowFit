## 二、提肛引导功能（Kegel Guide）

### 2.1 触发时机

- 仅在 **专注（focus）阶段结束** 时触发
- `useTimer.ts` 中 `remaining === 0` 检测到后，先将计时器状态置为 `kegel`（新增），再执行 `completePhase()`
- 用户点击「完成并休息」或「跳过」后，调用 `completePhase()` 正式进入休息阶段
- 若 `kegelEnabled === false`，直接跳过，行为与 v1.1 一致

### 2.2 数据结构扩展

#### `Settings`（`src/types/index.ts`）新增三个字段

```ts
kegelEnabled: boolean;       // 开关，默认 true
kegelReps: number;           // 每次提醒的组数，默认 10
kegelHoldSeconds: number;    // 每组保持秒数，默认 3
```

#### `DEFAULT_SETTINGS`（`src/constants/index.ts`）新增默认值

```ts
kegelEnabled: true,
kegelReps: 10,
kegelHoldSeconds: 3,
```

#### `TimerStatus`（`src/types/index.ts`）新增状态

```ts
export type TimerStatus = "idle" | "running" | "paused" | "kegel";
```

### 2.3 状态机流程

```
专注计时结束
  └─ kegelEnabled = true  →  status = "kegel"  →  显示引导卡
      ├─ 用户完成全部组数  →  completePhase()  →  进入休息
      └─ 用户点击跳过      →  completePhase()  →  进入休息

  └─ kegelEnabled = false →  completePhase()  →  进入休息（原有行为）
```

### 2.4 引导卡 UI（替换中列计时器区域）

```
┌─────────────────────────────┐
│  💪  提肛练习               │
│  专注结束，活动一下吧        │
├─────────────────────────────┤
│                             │
│   [ 收缩  ████████░░  3s ]  │  ← 每组倒计时进度条（kegelHoldSeconds 秒）
│         阶段标签            │  ← "收缩" / "放松（1s）"交替
│                             │
│   第 3 组 / 10 组           │  ← 当前进度文字
│   ●●●○○○○○○○               │  ← 点状进度指示器（最多显示 15 个点）
│                             │
├─────────────────────────────┤
│  💡 健康小知识（轮播）       │
│  规律提肛可增强盆底肌，      │
│  改善久坐带来的腰背不适      │
├─────────────────────────────┤
│  [跳过]      [完成并休息]   │
└─────────────────────────────┘
```

**节奏设计**：每组 = 收缩（`kegelHoldSeconds` 秒）+ 放松（1 秒固定）。进度条仅在收缩阶段动态缩减，放松阶段显示为满状态并标注"放松"。

**点状进度**：组数 ≤ 15 时每点代表一组；组数 > 15 时改为数字文字「第 X 组 / N 组」，不显示点阵。

**与 autoStartBreak 的交互**：引导卡期间计时器处于 `kegel` 状态，休息计时器不自动启动。用户完成或跳过后，若 `autoStartBreak = true`，进入休息时自动开始计时；行为与 v1.1 的 `autoStartBreak` 逻辑一致。

### 2.5 健康知识内置文案（5 条，循环轮播）

1. 提肛运动可增强盆底肌群，预防久坐导致的腰背酸痛
2. 每次收缩保持 3-5 秒后充分放松，训练效果最佳
3. 坚持每日练习可改善盆腔血液循环，有助于提升专注力
4. 提肛运动随时随地可做，无需器械，是上班族的隐形健身神器
5. 盆底肌强健有助于改善坐姿，减少脊柱长期压力

### 2.6 新增组件

| 组件/文件 | 职责 |
|-----------|------|
| `src/components/KegelGuide.tsx` | 引导卡主体，接收 `reps` / `holdSeconds` / `onDone` / `onSkip` props |
| `src/hooks/useKegel.ts` | 管理单次引导的组数倒计时状态（currentRep, phase, secondsLeft） |

**KegelGuide 不依赖 timerStore**，通过 props 纯驱动，便于独立测试。

### 2.7 设置面板扩展

在 `Header.tsx` 设置抽屉中新增「提肛提醒」分区：

```
提肛提醒
  [✓] 专注结束时自动提醒
  次数        [10] 组
  每次保持    [3]  秒  （建议 3-10 秒）
```

- 次数范围：1-30，整数步进
- 每次保持范围：1-10 秒，整数步进
- 开关关闭时，次数/秒数输入框灰显不可编辑

## 三、不在本次范围内

- 独立定时提肛提醒（非番茄钟绑定）
- 提肛历史记录统计
- 多种动作类型（仅提肛一种）
- 声音/震动反馈（沿用现有音效系统，暂不新增专属音效）

---

## 四、验收标准

1. Header 显示「FlowFit」，window title 为「FlowFit」
2. 专注计时结束后，若 `kegelEnabled = true`，计时器区域切换为引导卡
3. 引导卡完整走完 N 组后，自动调用 `completePhase()` 进入休息
4. 「跳过」按钮直接进入休息，不影响番茄计数
5. 设置面板可修改次数和每次保持秒数，修改后立即生效（下次触发时使用新值）
6. `kegelEnabled = false` 时，专注结束行为与 v1.1 完全一致
