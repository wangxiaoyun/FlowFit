市场调研 — 迭代功能优先级

对比 Forest、潮汐、番茄ToDo、Pomodomate 等主流应用，提炼出最有价值的缺失功能。请选出你想在下一版本实现的功能（可多选）。

A

🔁 长休息支持

每完成 N 个番茄钟自动触发长休息（默认 15 分钟）。设置里的 longBreakInterval / longBreakDuration 已有字段但逻辑未接入，补全即可。
✦ 几乎所有主流应用标配，实现成本低

B

🔥 连续天数 Streak

统计连续几天完成过番茄钟，并在统计面板展示最长 Streak 和当前 Streak。Reclaim、Athenify、Forest 均以此为核心留存机制。
✦ 最强留存动力，存储成本极低

C

🎵 白噪音 / 环境音

内置雨声、咖啡馆、白噪音等 3–5 种专注音效，用 Web Audio API 程序生成，无需外部资源。潮汐（Tide）以此为核心卖点，番茄 ToDo Pro 也提供白噪音。
✦ 差异化亮点，纯本地无网络依赖

D

📊 周统计图表

在统计面板展示近 7 天每日番茄数的柱状图，一眼看出本周生产力趋势。Athenify、Super Productivity、番茄·人生均提供周/月报表。
✦ 纯 SVG/CSS 实现，零依赖

E

🎯 每日番茄目标

设置今日目标番茄数（默认 8 个），统计面板显示完成进度条和百分比。Streak 判断也可以基于是否达成每日目标。
✦ 与 Streak 联动，强化目标感

F

🖥️ 系统托盘（桌面版专属）

Tauri 原生功能：关闭窗口时最小化到系统托盘，托盘图标显示剩余时间，右键菜单可开始/暂停/退出。纯桌面端差异化优势。
✦ 桌面版独有，Tauri 官方 API 支持

💡 我推荐优先选 A + B + D（长休息 + Streak + 图表），三者合力构成完整的"激励闭环"，且实现成本都较低。C（白噪音）差异化明显但工作量稍大。F（托盘）是桌面版专属亮点，值得一做。
